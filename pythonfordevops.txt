r	- Read	              - Opens an existing file for reading (default)
w	- Write	              - Creates a file or overwrites existing content
a	- Append	          - Adds content to the end of a file
x	- Exclusive creation  -	Creates a new file; fails if it already exists
r+	- Read + Write	      - Reads and writes without automatically deleting existing content
w+	- Write + Read	      - Reads and writes; truncates existing content
a+	- Append + Read	      - Appends and reads; creates the file if missing
x+	- Create + Read/Write - Creates a new file for reading and writing
rb	- Read Binary	      - Reads binary files
wb	- Write Binary	      - Writes binary data; overwrites existing content
ab	- Append Binary	      - Appends binary data
rb+	- Read/Write Binary	  - Reads and writes an existing binary file
wb+	- Write/Read Binary	  - Creates or truncates a binary file for reading and writing
ab+	- Append/Read Binary  - Appends and reads binary data
t	- Text	              - Text mode (default); combined with another mode such as rt

for
---

while
-----

while count < 5:

break and continue

for i in range (10):
    if i == 5:
        break
    print (i)

for i in range (10):
    if i == 5:
        continue
    print (i)
